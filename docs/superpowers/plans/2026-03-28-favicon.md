# Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the blank `static/favicon.ico` with a sage-green tilted leaf icon that matches the blog's visual identity.

**Architecture:** Write the SVG source to `static/favicon.svg`, then run a one-off Node.js script (`scripts/generate-favicon.js`) that uses the project's existing `sharp` package to render the SVG at 16×16 and 32×32 px, packs both PNGs into a valid ICO binary, and writes it to `static/favicon.ico`.

**Tech Stack:** Node.js (v24), `sharp` (already in `node_modules` via `gatsby-plugin-sharp`), ICO binary format (hand-packed, no extra dependency).

### Task 2: Write the favicon generation script

**Files:**
- Create: `scripts/generate-favicon.js`

The ICO format is: a 6-byte header, one 16-byte directory entry per image, then the raw PNG bytes concatenated. Width/height in each entry are read from the PNG's IHDR chunk (bytes 16–19 and 20–23 after the PNG signature).

- [ ] **Step 1: Create `scripts/generate-favicon.js`**

```js
#!/usr/bin/env node
'use strict';

const sharp = require('sharp');
const fs = require('fs');
const path = require('path');

const root = path.join(__dirname, '..');
const svgPath = path.join(root, 'static', 'favicon.svg');
const icoPath = path.join(root, 'static', 'favicon.ico');

async function main() {
  const svgBuffer = fs.readFileSync(svgPath);

  const [png16, png32] = await Promise.all([
    sharp(svgBuffer).resize(16, 16).png().toBuffer(),
    sharp(svgBuffer).resize(32, 32).png().toBuffer(),
  ]);

  fs.writeFileSync(icoPath, packIco([png16, png32]));
  console.log('Written: static/favicon.ico (16×16 + 32×32)');
}

function packIco(pngs) {
  const count = pngs.length;
  const headerSize = 6;
  const entrySize = 16;
  const dataStart = headerSize + entrySize * count;

  // ICONDIR header
  const header = Buffer.alloc(headerSize);
  header.writeUInt16LE(0, 0); // reserved
  header.writeUInt16LE(1, 2); // type: 1 = ICO
  header.writeUInt16LE(count, 4);

  // ICONDIRENTRY per image
  let offset = dataStart;
  const entries = pngs.map(buf => {
    // PNG IHDR: signature (8) + chunk length (4) + "IHDR" (4) + width (4) + height (4)
    const w = buf.readUInt32BE(16);
    const h = buf.readUInt32BE(20);
    const entry = Buffer.alloc(entrySize);
    entry.writeUInt8(w >= 256 ? 0 : w, 0);  // width  (0 = 256)
    entry.writeUInt8(h >= 256 ? 0 : h, 1);  // height (0 = 256)
    entry.writeUInt8(0, 2);                  // color count (0 = no palette)
    entry.writeUInt8(0, 3);                  // reserved
    entry.writeUInt16LE(1, 4);               // color planes
    entry.writeUInt16LE(32, 6);              // bits per pixel
    entry.writeUInt32LE(buf.length, 8);      // size of image data
    entry.writeUInt32LE(offset, 12);         // offset of image data
    offset += buf.length;
    return entry;
  });

  return Buffer.concat([header, ...entries, ...pngs]);
}

main().catch(err => { console.error(err); process.exit(1); });
```
